--------------------------------------------------------------------------------
1. OVERVIEW & TECH STACK
--------------------------------------------------------------------------------
Whisprlive is a real-time, anonymous Q&A and audience engagement platform 
designed for speakers, event hosts, creators, educators, and livestreamers.

Tech Stack:
  - Frontend: React (Vite), React Router v6, Lucide React Icons, Socket.io Client,
              Axios, Google OAuth SDK, QR Code Generator.
  - Backend: Node.js, Express.js, Socket.io Server, Prisma ORM, PostgreSQL.
  - Authentication: JWT, Bcrypt, Google OAuth 2.0 Client.
  - Payments: Razorpay Payment Gateway (Dual-currency INR/USD).
  - Geolocation & Device Tracking: geoip-lite, ua-parser-js.
  - Analytics & Security: Google Analytics 4 (GA4), Express Rate Limiters, COOP.

--------------------------------------------------------------------------------
2. USER AUTHENTICATION & ACCOUNT MANAGEMENT
--------------------------------------------------------------------------------
  • Standard Email/Password Auth:
    - User registration with password hashing using bcrypt.
    - User login issuing 3-hour JWT access tokens.
  • Google One-Tap & OAuth 2.0 Sign-In:
    - Seamless 1-click sign-in and account creation using Google Auth.
    - Server-side ID token verification via google-auth-library.
  • Account Profile Sync:
    - Dedicated /api/user/me endpoint to fetch user profile, active plan tier, 
      and available Room Pass credits.
  • Brute-Force Rate Limiting:
    - Auth endpoints protected by authLimiter (max 10 attempts / 15 minutes / IP).

--------------------------------------------------------------------------------
3. ROOM & Q&A SESSION MANAGEMENT
--------------------------------------------------------------------------------
  • Event Name / Session Title Field:
    - Custom title input field ("Event Name / Session Title") displayed prominently across 
      dashboard and public Q&A pages.
  • Instant Room Creation:
    - Hosts can launch live Q&A rooms immediately.
  • Scheduled Sessions (Room Pass / Host Tiers):
    - Ability to schedule rooms for a future start time with real-time countdown timers.
    - Solo Free tier restricted to "Start Now" only.
  • Unique Nanoid Room Codes:
    - Generates short 8-character unique room identifiers for simple URL sharing.
  • Active Session Control Center:
    - Real-time live countdown timer (MM:SS) showing remaining room time.
    - Option to manually end/close a live session early at any time.
  • Auto-Expiration & Auto-Closure:
    - Rooms automatically close when duration expires or when plan message capacity 
      limit is reached (Solo: 15 msgs, Room Pass: 500 msgs).

--------------------------------------------------------------------------------
4. REAL-TIME AUDIENCE ENGAGEMENT & SHARING
--------------------------------------------------------------------------------
  • WhatsApp Share Button:
    - Direct 1-click WhatsApp link sharing ("https://wa.me/?text=...") on active session 
      dashboard, QR code popups, and public Q&A pages.
  • Real-Time WebSocket Delivery (Socket.io):
    - Submitted audience questions instantly appear on host dashboard without refresh.
  • Live Upvoting & Unvoting:
    - Real-time upvote counting and score synchronization.
  • Mark as Answered / Unanswered:
    - Hosts can check off answered questions with live badge sync.
  • Question Search & Filtering:
    - Search active questions, filter by All / Unanswered / Answered, and sort by Newest / Popular.
  • Character Limit & Spam Protection:
    - 300-character maximum per question with live counter.
    - Rate limiter (max 10 questions / minute / IP).

--------------------------------------------------------------------------------
5. PUBLIC AUDIENCE ASK PAGE (/ask/:roomCode)
--------------------------------------------------------------------------------
  • Zero Friction (No Login Required):
    - Audience members join and post questions 100% anonymously without signing up.
  • WhatsApp Sharing & Copy Link:
    - 1-click WhatsApp share button and link copy for attendees.
  • Live Room Status Banner:
    - Displays Scheduled, Active, or Expired room states dynamically.
  • Interactive QR Code Generator:
    - Built-in QR code popup modal for quick scanning by event attendees.
  • Interactive Demo Mode (/ask/demo):
    - Sandboxed demo room for testing question submission without an account.

--------------------------------------------------------------------------------
6. USER SUGGESTIONS & FEEDBACK WIDGET
--------------------------------------------------------------------------------
  • Floating Feedback Button (FeedbackWidget.jsx):
    - Floating action button at bottom-right corner ("Feedback") available across all pages.
  • Feedback Modal:
    - Interactive popup allowing users/visitors to select feedback type (Feature Idea, 
      Report Bug, General Feedback), type their message, and provide an optional contact email.
  • Feedback Database Storage:
    - Backend POST /api/feedback endpoint storing submissions in the Feedback model table in PostgreSQL.

--------------------------------------------------------------------------------
7. AUDIENCE INTELLIGENCE & DEVICE TRACKING
--------------------------------------------------------------------------------
  • Granular Hardware Detection:
    - Parses User-Agent header via ua-parser-js to track client OS, browser, and hardware model 
      (e.g., "Mobile (Android 11 / Chrome)", exact model: "Realme RMX3085", "Samsung SM-S918B").
  • Geolocation & IP Tracking:
    - Resolves client IP to City and Country using geoip-lite.
  • Host Metadata Inspection:
    - Displays device model, location, and IP metadata to the host.

--------------------------------------------------------------------------------
8. PRICING, TIERS & LAUNCH MATRIX
--------------------------------------------------------------------------------
  • Active Launched Plans:
    - SOLO (Free): 3 rooms/month, 15-min max duration, 15 max messages/room, Start Now only, 
      7 days history retention, no export.
    - ROOM PASS ($5 / ₹399): 1 room (24 hours), 500 max messages/room, Scheduled start enabled, 
      30 days history retention, .txt transcript export.
  • Coming Soon Plans & Email Waitlist:
    - HOST ($9/mo · ₹349/mo): Unlimited rooms, 60-min timers, 1,000 msgs/room, 90 days retention.
    - STUDIO ($19/mo · ₹799/mo): Unlimited rooms, 120-min timers, 2,500 msgs/room, 1 yr retention.
    - "Notify Me" Waitlist Button: Collects interested users' emails into database (PlanWaitlist table) 
      via POST /api/waitlist.
  • Geo-Dynamic Currency Detection:
    - Detects visitor country (₹399 INR for India, $5 USD international).
  • Razorpay Integration:
    - Order creation, HMAC SHA-256 verification, and instant Room Pass crediting.

--------------------------------------------------------------------------------
9. SESSION HISTORY, RETENTION & EXPORT
--------------------------------------------------------------------------------
  • History Retention Enforcement:
    - Automatically filters past rooms by retention window (7 days for Solo, 30 days for Room Pass).
  • Past Session Question Inspector:
    - Modal popup to review past session questions with search & filter support.
  • Download Session Transcript (.txt):
    - 1-click plain text export (/api/rooms/:roomId/export) for rooms with Room Pass or Host tier.
  • Session Deletion:
    - Delete unwanted past rooms from host record.
